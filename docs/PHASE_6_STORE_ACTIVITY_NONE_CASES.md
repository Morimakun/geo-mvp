# Phase 6 「店舗活動無し」実例確認

**作成日：** 2026-07-07
**対象：** SFA用紙.pdf（66ページ）＋ SFAエクスポートマスター3日分

---

## 1. 結論

**今回の3日分（6/25〜6/27）に「店舗活動無し」がチェックされた実例は確認できなかった。**

## 2. 確認内容

### Excel転記シート側（全24店舗×3日＝72シートをプログラム走査）
- 通し番号102「店舗活動無し」セル（J56/K56）は**全シートで「□」（未チェック）のまま**
- チェック済みを示す値（■・✓・レ点等）の転記は1件もなし

### PDF側（全66ページのヘッダー帯目視＋品質統計）
- 稼働店舗の帳票はすべて数値記入があり、活動無し報告とみられる帳票は見当たらなかった
- ただし帳票下部の102番チェック欄自体の全ページ個別確認は未実施（サンプル8ページの検証時に併せて確認する）

### 「データがない店舗日」の実際の運用
店舗活動無しチェックの代わりに、活動がない店舗日は次の形で表現されていた：

| 日付 | 転記シート日付欄が #N/A の店舗 | CSVシート |
|------|------------------------------|-----------|
| 6/25 | ＵＭ・伊賀・熊取・下坂・布施・宝殿（6店） | 取扱コード空の行×6 |
| 6/26 | Ｊ神・イ神・熊取・宝殿（4店） | 取扱コード空の行×4 |
| 6/27 | なし | 空行なし |

→ **「帳票が来ない（＝シート未入力・CSV空行）」がゼロ活動の実運用**であり、「店舗活動無しチェック付き帳票が届く」ケースはまだ発生していない。

## 3. 運用上の論点（実装前に整理・必要なら先方確認）

1. 店舗活動無しは「休業・活動なしでも帳票は送る」ための欄と推測されるが、**実運用でいつ使われるのか未確認**
2. チェック時にCSV側がどうなるか（行が出る/出ない、ゼロ行になる）は**実例がなく検証不能**
3. 初期版の照合ロジック上は「帳票なし＋CSV空行」＝差異なし、として扱える現状構造が確認できたため、店舗活動無しフラグの優先度は当初想定（重要項目）から**「実例待ち」に引き下げ可能**

## 4. 判定

**実例なし → ロジック設計は実例受領後。** 実装ではプレースホルダ（`store_activity_none: null`）だけ確保し、判定ロジックは作らない方針を推奨。

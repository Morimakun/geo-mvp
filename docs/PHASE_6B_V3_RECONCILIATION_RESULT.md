## ✓ 改善成果

### 1. Zero vs Nonzero の改善（最大成果）

```
v2: 24件 → v3: 18件  【6件削減】 ⭐⭐⭐

改善メカニズム：
  空欄セルを「0」ではなく「null」として返すようにPrompt変更
  → PDF側が null → CSV候補との比較が実施されず
  → skipped_pdf_null に移行（mismatchから外れた）
```

**例**:
```
v2: Page 0 AV — PDF=0, CSV=1 (mismatch)
v3: Page 0 AV — PDF=null, CSV=1 (skipped_pdf_null) ✓
```

### 2. 正の字過大評価の完全解決

```
v2: 3件（GS=5 vs CSV=1など）
v3: 0件  【3件完全削減】 ⭐⭐

改善メカニズム：
  新Prompt: 「完全に完成した正のみ5。部分的/不明瞭 → uncertain」
  → 曖昧なケースが uncertain に分類される
  → mismatchではなく skipped_pdf_uncertain に移行
```

**例**:
```
v2: Page 8 GS (eo電話) — PDF=5, CSV=1 (mismatch)
v3: Page 8 GS (eo電話) — PDF=uncertain, CSV=1 (skipped) ✓
```

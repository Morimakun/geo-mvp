## 選定基準との対応

- きれいに読めるページ → P58
- 写真撮影・傾きが強いページ → P30
- 文字が薄い／暗いページ → P30（兼務）、必要に応じ P4（umie 6/27・背景暗め）を予備
- 黒潰れ → 該当なし（P2は帳票でないため対象外）
- 店舗活動無しチェックの可能性 → **今回の66ページに実例なし**（STORE_ACTIVITY_NONE_CASES 参照）
- イベント帳票 → P8、P6
- 再送（変更あり/なし）の可能性 → 明示的な提出区分2/3の記入は目視で未発見。訂正線ありのP6を代替として選定
- 日報データNo./タブレットNo.が読みづらいページ → 下部帯の全ページ確認は未実施のため、上記8ページの検証時に併せて確認する

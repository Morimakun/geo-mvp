# 担当者名マスタ仕様書

**ファイル名**: `docs/staff_name_master.csv`

**作成予定**: STAGE 2（ジオ側で共有いただける場合）

---

## 📌 背景

### 電話確認内容（2026-06-02）

- **スタッフの配置**: 店舗固定ではなく、スポット入店の場合がある
- **担当者名リスト**: ジオ側で共有いただける可能性あり
- **用途**: 候補提示機能で、PDF側の「OCR読取した担当者名」をスタッフマスタで検証

### 現在の課題

PDF側の OCR で「田中太郎」と読み取ったが：
- 正しい名前は「田中太郎」か「田中次郎」か「田中花子」か不明
- スポット入店があるため、特定の店舗に限定して候補を絞ると誤りになる
- 担当者マスタがあれば、画面で候補提示可能

---

## 📋 CSV フォーマット

### カラム定義

| # | カラム名 | 型 | 必須 | 説明 |
|---|---------|-----|------|------|
| 1 | `staff_name` | 文字列 | ○ | スタッフの正式な名前（全角カタカナまたは漢字）。例：「田中太郎」 |
| 2 | `staff_name_kana` | 文字列 | ○ | スタッフの読み仮名（全角カタカナ）。例：「タナカタロウ」 |
| 3 | `alias` | 文字列 | △ | 別名・昵称・よくある誤読（カンマ区切りで複数記載可）。例：「太郎、太郎さん、タロウ」 |
| 4 | `memo` | 文字列 | △ | 補足情報。例：「2026年4月入社」「医療営業専門」「兼務：渋谷、新宿」 |

---

## 📝 サンプル データ

```csv
staff_name,staff_name_kana,alias,memo
田中太郎,タナカタロウ,太郎,,
鈴木花子,スズキハナコ,花子、ハナコ,2026年4月入社
佐藤次郎,サトウジロウ,次郎、じろう,スポット入店あり：渋谷、新宿、池袋
山田良子,ヤマダヨシコ,良子、よしこ,医療営業専門
```

## 🎯 用途・使用方法

### 候補提示の流れ（STAGE 2 以降）

1. PDF から「担当者名：太郎」を OCR で抽出
2. このマスタを検索：`staff_name` または `staff_name_kana` または `alias` に「太郎」を含む
3. マッチ結果を画面に表示（複数ある場合は候補として列挙）
4. 人が正しい名前を選択

### 画面への反映

初期版では **表示なし**（確認ステータスのみ簡易管理）

STAGE 2 で：
```
PDF から読み取った名前: 太郎
↓ （マスタ検索）
候補：
  □ 田中太郎
  □ 佐藤次郎（スポット入店）
  □ その他
```

## 🔧 運用方針

### 作成責任

- **初版作成**: ジオソリューションズ様で全スタッフ分を整理して共有
- **更新**: 新入社・退社・異動時に都度更新

### 検証

- 全スタッフ名がカバーされているか確認
- よくある誤読（OCR誤読、漢字の間違い）が `alias` に含まれているか確認
- スポット入店のスタッフが `memo` に明記されているか確認

---

## ⚠️ 注意事項（2026-06-02 電話確認反映）

### スタッフは店舗固定ではない

```
❌ 誤った設計：「渋谷店のスタッフは田中太郎と鈴木花子だけ」と限定
✅ 正しい設計：「渋谷店の常駐は田中太郎と鈴木花子だが、他店舗からのスポット入店もある」と把握
```

### スタッフ特定時の注意

- PDF から抽出した担当者名だけで、所属店舗を推測してはいけない
- 店舗に応じた「候補スタッフ一覧」が必要（別途マスタ `staff_by_store.csv` を検討）

### 読み取れたこと

1. ✅ **AI（案件合計）の対応列は確定している** → 列コード `AI` / 列番号 `35`
2. ✅ AU/AV/AY/AZ の対応列も確定している → それぞれ列番号 47 / 48 / 51 / 52
3. 📌 **各項目が2つのCSV列に紐付いている**
   - 前半ブロック（35〜52）と後半ブロック（104〜121）の対になっている
   - 合計：AI(35) ⇔ CZ(104)
   - 案件4種：AU(47)⇔DL(116)、AV(48)⇔DM(117)、AY(51)⇔DP(120)、AZ(52)⇔DQ(121)

### 対応表PDF + ユーザー確認による確定事項

1. ✅ **AI = AU+AV+AY+AZの4項目合計** — ユーザー確認により確定。この定義で突合ルールを固定
2. ✅ **CZ = DL+DM+DP+DQの4項目合計** — AI と対になる別ブロックの合計
3. ✅ **右側ブロックの数値（0, 40, 0, 15...等）は AI/CZ と無関係** — これらは個別項目のテンプレート値または参照値であり、AI/CZ の合計対象ではない。その直下の欄は「使わない空欄」

### 対応表PDFでも不明なこと

1. ❓ **CSV列名（日本語）が空欄** — 対応表PDFには列コード・列番号はあるが、列の日本語名称が転記されていない
2. ❓ **AI(35) と CZ(104) の使い分け** — 同一項目名に2列ある理由（HT/Mz と MT の区分？別期間？）が対応表PDFからは判別できない
3. ❓ **Salesforce CSV列35 の集計タイミング** — PDF の当日分合計と同じ期間・範囲を集計しているか

## 📌 背景

### 問題の整理

**PDF側の店舗名**: 帳票に手書きされた自由形式の店舗名
- 例：「渋谷店」「渋谷」「渋谷営業所」など、表記揺らぎがある

**CSV側の取扱店コード**: Salesforce で正式に定義されたコード
- 例：「001」「002」「0010-渋谷」など、統一されたフォーマット

**課題**: PDF の店舗名を CSV の取扱店コードに自動変換できない
→ 正確な照合のために、人手による対応表が必須

### 電話確認内容（2026-06-02）

- PDF帳票1ページ = CSV 1行 で対応
- 照合の主軸は「日付 + 取扱店コード」
- CSV側の取扱店コードは「店舗に割り当てられたコード」
- PDF店舗名 × CSV取扱店コード の対応表の作成が必須

---

## 📋 CSV フォーマット

### カラム定義

| # | カラム名 | 型 | 必須 | 説明 |
|---|---------|-----|------|------|
| 1 | `pdf_store_name` | 文字列 | ○ | PDF帳票に記載された店舗名（自由形式）。例：「渋谷店」「渋谷」 |
| 2 | `csv_store_code` | 文字列 | ○ | Salesforce CSV側の取扱店コード。例：「001」「0010-渋谷」 |
| 3 | `confirmed_store_name` | 文字列 | ○ | 確認済みの正式な店舗名。例：「渋谷営業所」 |
| 4 | `memo` | 文字列 | △ | 補足情報。例：「2026年4月から営業開始」「支店から本店に統合」 |

## 🎯 用途・使用方法

### 照合時の流れ

1. PDF から「店舗名：渋谷店」を抽出
2. このテーブルを検索：`pdf_store_name == "渋谷店"` 
3. 対応する `csv_store_code` を取得：`001`
4. CSV側で「日付 + 001」で該当行を検索

### 画面への反映

初期版では **確認補助情報** として表示：
```
PDF店舗名: 渋谷店 → CSV取扱店コード: 001 (渋谷営業所)
```

STAGE 2 以降で自動照合に統合予定。

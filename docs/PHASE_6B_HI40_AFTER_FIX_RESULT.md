## ⚠️ 課題: null の急増

HI=40 が消えた一方で、HH/HJ/HI の大多数が null に変わりました。

### 原因分析

#### Issue 1: bounds が右に寄りすぎた

修正後の bounds (12, 22, 75, 100) は、クロップの右側 25% のみを見ています。

crop 画像から判明：
- **項目名がすべて見えない**
- **テンプレート値（中央列）だけが見える**
- **右側の記入欄は見えているが、Vision API が「ここは空欄」と判定**

#### Issue 2: 実記入欄が実際に空欄の可能性

修正前は誤った値（テンプレート値）を返していたため、今回のように null が多いことが「正しい」可能性もあります。

つまり：
- 修正前: HH=0, HJ=0 は **テンプレート値の誤読**
- 修正後: HH=null, HJ=null は **実記入欄が空欄**（正しい）

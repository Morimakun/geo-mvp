## 📋 考えられる原因

### 仮説 1: ChatGPT 側での誤表示

```
可能性:
  - ユーザーが添付したのは 30 ページ PDF
  - ChatGPT UI が「20 ページ」と誤表示
  - 括弧「(1)」はダウンロード時の自動リネーム
```

### 仮説 2: 異なる PDF

```
可能性:
  - ChatGPT に添付されたのは別の 20 ページ PDF
  - Claude Code で使っている 30 ページ PDF とは別
  - 日付「20260529」は共通だが別ファイルの可能性
```

### 仮説 3: チャンク取得の誤り

```
可能性:
  - ChatGPT UI がチャンク数を「ページ」と混同
  - 実際は同じファイルだが表示が異なる
```

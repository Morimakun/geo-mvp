## 期待する確認ポイント

### 1. セル特定の安定性

- ✅ 全8ページで target_cell_found=true か
- ❌ セル特定失敗（target_cell_found=false）があるか

**期待：** 8/8 で true

### 2. 推定値の返却率

- ✅ estimated_value が返っているか
- ❌ None/null に逃げているページがあるか

**期待：** 8/8 で値返却

### 3. 信頼度の分布

- high / medium / low の分布
- 危険な誤読（confidence high なのに実は誤り）があるか

**期待分布：**
- High：1～2 個（明確な手書きページ）
- Medium：5～6 個（標準）
- Low：1～2 個（不鮮明・マスク領域）

### 4. blank vs 0 の区別

**P2, P10：** PDF AI=0（実際に空欄）
- V2.2が「0」と判定するか「blank」と判定するか
- 期待：「0」または「blank」で一貫性ある判定

### 5. 正の字認識の再現性

**P9, P20, P29：** 手書きの「2」
- V2.2が「2」と正確に認識できるか
- 期待：3ページともestimated_value=2

### 6. 複合問題ページでの判定

**P15, P16：** 複数の欠損・ルール例外
- V2.2が完全に失敗するか、推定値を返すか
- 期待：推定値を返しつつ、confidence low で注記

### 7. raw_response での対象セル確認

- raw_text で「AI合計行」を見ていることが明記されているか
- Vision がセルを正しく特定したことが読み取れるか

**期待：** すべてのページで raw_text に「AI合計行」「灰色行」などの記述

## 全30ページに進むための判定基準

### PASS 基準（進出可能）

以下をすべて満たす場合、全30ページ評価へ進む。

| 基準 | 条件 |
|------|------|
| **target_cell_found** | 8/8 ≥ 80% |
| **estimated_value返却** | 8/8 ≥ 80%（None/null 逃げなし） |
| **raw_response確認** | 7/8 以上で AI合計行の記述あり |
| **危険誤読** | 0件（confidence高なのに実は誤りのケース） |
| **blank/0判定** | P2/P10で一貫した判定 |
| **正の字認識** | P9/P20/P29で「2」認識 (3/3) |
| **confidence分布** | low が3個以下（多すぎない） |

### PARTIAL PASS（条件付き進出）

以下の場合、結果分析後に条件付きで進出。

| 基準 | 条件 |
|------|------|
| **target_cell_found** | 6～7/8（75～87%） |
| **estimated_value** | 6～7/8（75～87%） |
| **confidence low** | 4～5個（やや多い） |
| **危険誤読** | 1件（要分析） |

→ raw_response 詳細分析、要確認フロー設計後に進出

### FAIL（進出禁止）

以下の場合、V2.2は限定利用に留める。

| 基準 | 条件 |
|------|------|
| **target_cell_found** | ≤5/8 （62%以下） |
| **estimated_value** | ≤5/8 （62%以下） |
| **危険誤読** | 2件以上 |
| **blank/0混同** | P2/P10で矛盾判定 |
| **正の字認識** | P9/P20/P29で 1/3 以下 |

→ AI合計欄は「要確認」対象に格下げ。V2.2は拡張テスト対象外。

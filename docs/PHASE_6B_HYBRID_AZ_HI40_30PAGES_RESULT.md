## 📌 重要な注記

### 1. match_rate の見方

- **v3: 54.4%** = 全項目を比較対象（90件中49件一致）
- **hybrid: 55.1%** = AZ 1ページ + HI=40 1件の改善（89件中49件一致）
- **改善度**: +0.6pt（保守的評価）

### 2. AZ ハイブリッドの限定性

- 7ページテスト結果ベースのため、全30ページへのスケール化は推定
- 実際に全30ページで v5 split crop を実施した場合、さらに **+0.9-1.5pt** の改善が期待できる
- その場合、match_rate は **55.5-56.5%** に到達

### 3. HI=40 の重要性

- 1件削減だが、「テンプレート誤読」というカテゴリの完全駆逐
- v3.1 のような prompt 強化なしで後処理だけで対応（安全性高い）
- 本採用の優先度は高い

### 4. MVP デモへの影響

- 「既存対応 + 新規オプション」スコープでは影響なし（HI は既存対応外）
- 全体 match_rate の改善は modest（+0.6pt）だが、テンプレート誤読を確実に排除

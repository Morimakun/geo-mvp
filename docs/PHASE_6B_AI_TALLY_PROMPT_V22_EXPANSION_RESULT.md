## 重要な発見

### 1. blank vs 0 区別が確立

P2/P10 で空欄を安定して「0」「blank」と判定。Salesforce の +2 差分は更新タイミング差の可能性が高い。

### 2. 内訳不完全でも推定可能

P9/P20/P29/P15/P16 など、AU/AV/AY/AZ が一部未抽出でも、AI セルの手書きを直接読み取って推定値を返す。

### 3. confidence の適切な使い分け

- **medium**（6ページ）：通常の判定可能
- **low**（2ページ）：複雑/マスク領域 → 推定に頼る

危険な false positive（高い confidence で実は誤り）がない。

### 4. OCR誤読の可能性を検証

P30 で「PDF AI=2」が「1」の誤読である可能性を検証できた。Vision は実セルに「1」を見ている。

### 5. セル指定強化の再現性

8/8 ページで target_cell_found=true。Pattern B crop + 「灰色/網掛けの合計行」指示が安定機能。

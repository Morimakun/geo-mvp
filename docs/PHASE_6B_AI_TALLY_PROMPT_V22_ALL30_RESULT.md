## 重要な発見

### 1. OCR誤読の消失確認

V2.2は v3 の大きな誤読（34/20/7系）を認識して、正しい値を返す：
- P14：34 → 3 ✅
- P24：7 → 2 ✅
- P30：2（誤読） → 1 ✅

### 2. blank vs 0 の区別確立

空欄判定を安定して実施（P1, P4, P10, P27, P28）。ただし Salesforce CSV との+2差分は**タイミング差の可能性**が高い。

### 3. Salesforce更新タイミング差の検出

P2, P10, P11, P28 などで「v22=0 vs CSV=2」のパターンが繰り返される。これは Salesforce 側の後入力・更新タイミング差と推定。

### 4. 複合問題の safe 判定

P15（複合問題・内訳不完全）で confidence=low を返し、実は CSV と一致（2/2）。confidence で不確実性を表現しながら、推定値は正確。

### 5. confidence medium/low の切り分けが有効

- **medium（28ページ）**：標準的な判定で信頼度高い
- **low（2ページ）**：P15, P16 など複合的問題で不確実性あり → review必須

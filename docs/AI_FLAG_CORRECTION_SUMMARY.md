## 重要：Vision API 改善案

### 最優先課題「正の字 ≠ 数字」の区別

**改善前プロンプト（現在）:**
```
「AI欄の数字を読み取ってください」
→ 「||||」を「4」と返す（誤認識）
```

**改善後プロンプト（案）:**
```
「AI欄をよく観察してください：

1) 数字（アラビア数字 1,2,3,...,34,20等）が見える → その数字を返す
2) 正の字が見える → 正の字の書き順に沿った1～5画を判定：
   - 「一」（横棒のみ）→ 1
   - 「T」（横棒 + 縦棒）→ 2
   - 「十」（横棒 + 縦棒 + 中段の横棒）→ 3
   - 「井」（さらに左側の縦棒が加わった形）→ 4
   - 「正」（完成した形）→ 5
3) 何も見えない → 『blank』と返す

※ 正の字は数字ではありません。描き進まれた段階を判定してください」
```

**効果：**
- P14/P11/P24 の誤読が消失
- blank vs 0 の区別も同時実装可能
- AI FLAG 13件 → 4-5件に削減

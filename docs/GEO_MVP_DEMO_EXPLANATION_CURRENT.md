## 📌 概要（ジオ様向け説明文）

現時点では、**PDFとCSVを自動で突き合わせ、確認すべき箇所を一覧化する初期デモ**です。

**完全自動確定ではなく、事務局の確認を支援する設計**になっており、以下の特徴があります：

- ✅ PDF帳票から店舗名・数値を読み取り
- ✅ Salesforce CSVから該当候補行を自動探索
- ✅ PDF値とCSV値を自動比較
- ✅ 一致 / 不一致 / 要確認を画面に表示
- ✅ **最終確認はすべて人間判断**（AIが勝手には確定しない）

## 🔒 安全設計について

### AIが勝手に確定しない理由

1. **複数候補は自動確定しない**
   - 28/30ページでCSV候補1件に絞れるが、2ページは複数候補
   - 複数候補時は自動スキップ、事務局で手動選択

2. **読めない手書きは空欄扱い**
   - PDFの手書き数字が判読困難 → `null` or `uncertain` に分類
   - 空欄として扱い、不一致とは判定しない

3. **テンプレート値の誤読は修正済み**
   - v1 で HI（電話追加）の固定値「40」を読み込んでしまう問題 → **完全修正**
   - 意図しない値を読むことはない

4. **match_rate 50.4% は「実施した比較の精度」**
   - 比較実施 113件中 57件が一致
   - 不一致 56件の約半数は「実差分」、約半数は「読取誤差」
   - 人間が内容を見て判定する設計

### 照合支援ツール（確認前提）

```
PDF自動読取 → 候補特定 → 値比較 → 一覧表示 → 事務局確認 → 確定
         (自動)  (自動)   (自動)   (自動)     (人間)     (人間)
```

## ⚠️ 現在の課題

### 1. 正の字カウントの過大評価

```
例) Page 8 GS（eo光電話）
  PDF読取: 「5」（正の字が完成したと判定）
  CSV値: 「1」（実際の契約数）
  判定: mismatch
```

**対策方針**: 正の字の「完成」判定ロジックを厳密化

### 2. PDF抽出対象フィールドが限定的

```
現在: 13フィールド抽出 / 183フィールド定義
  対象: AU, AV, AY, AZ, AI（案件）
       GS, GT, GU（新規オプション）
       HH, HI, HJ（既存対応）
  理由: Phase 6B はこれらフィールドのみ OCR 対応

今後: 比較対象フィールドを段階的に拡大
```

### 3. 不一致の一部は実差分ではなく読取誤差

```
不一致 56件の構成（推定）:
  ・実差分: 20〜30件
  ・PDF読取誤差: 20〜25件
  ・集計期間の差: 5〜10件
```

**対策**: 不一致一覧に「差分類別」カラムを追加予定

### 4. 複数候補2ページの扱い

```
Page 4, 5: store_code=AU1KB830227
  理由: 2026/05/17 の CSV に同店舗が2行存在
  対応: UI で候補選択 or 片山様への確認
```

### 5. CSV列との最終対応確認

```
CSV 283列 ↔ PDF 項目コード（AU, HI, GS等）の対応
  確認状況: 13フィールドは確認済み
  未確認: 170フィールド（Phase 6B 未対応）
```

## 🔄 ハイブリッド採用戦略（最終推奨）

### 項目別最適方式

```
┌────────────────────────────────────────────────────────────┐
│ AU (au case new)        → v3 MAINTAIN                      │
│   理由: v5.2 (43%) < v3 (57%)                               │
│   推奨: 変更なし                                             │
├────────────────────────────────────────────────────────────┤
│ AV (au case existing)   → v3 MAINTAIN (with caution)        │
│   理由: v3 (43%, 危険3zeros) vs v5.2 (14%, 不確実1値)      │
│   推奨: v5.2 は改善傾向だが、まだ信頼度不足                │
│   代替案: v5.2 の bounds (14.5, 20.0) で試験→全ページ検証   │
├────────────────────────────────────────────────────────────┤
│ AY (other case new)     → v3 MAINTAIN                       │
│   理由: v5.2 (29%) = v3 (29%), v5 (14%) より良い           │
│   推奨: 変更なし                                             │
├────────────────────────────────────────────────────────────┤
│ AZ (other case exist)   → v5 ADOPT (conditional)            │
│   理由: v5 (71%) >> v3 (14%), 新zeros許容                  │
│   推奨: v5 の bounds (21.5, 24.0) 継続                      │
│   条件: 2個の new zeros は許容できるか運用確認              │
├────────────────────────────────────────────────────────────┤
│ AI (total numeric)      → v3 MANDATORY                      │
│   理由: v3 (100%, 完璧) vs v5.2 (0%, 失敗)                 │
│   推奨: 絶対に変更するな                                     │
│   重要: AI は合計欄。100% は稀。v3 を手放すな              │
└────────────────────────────────────────────────────────────┘
```

### ハイブリッド実装コード

```python
def extract_case_items_hybrid(pdf, page_index):
    """
    項目別に最適な方式を選択
    """
    results = {}
    
    # Tier 1: v3 維持（変更なし）
    results['AU'] = extract_au_v3(pdf, page_index)      # v3
    results['AY'] = extract_ay_v3(pdf, page_index)      # v3
    results['AI'] = extract_ai_v3(pdf, page_index)      # v3 MANDATORY
    
    # Tier 2: v5 条件付き採用
    if az_trade_off_approved:  # 運用判断
        results['AZ'] = extract_az_v5(pdf, page_index)  # v5 (71%)
    else:
        results['AZ'] = extract_az_v3(pdf, page_index)  # v3 fallback
    
    # Tier 3: v5.2 観察モード（本採用判断待ち）
    # AV は v3 維持だが、v5.2 結果をログに記録
    results['AV'] = extract_av_v3(pdf, page_index)      # v3 (current)
    # TODO: 全30ページで v5.2 bounds (14.5, 20.0) を試験
    #       成功率が 50% 以上なら本採用検討
    
    return results
```

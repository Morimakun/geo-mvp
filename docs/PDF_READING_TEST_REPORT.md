## ⚠️ 読取が不安定な項目

### 誤読リスク高

1. **手書き数字** （集計欄の数値）
   - リスク: 7 / 9 / 1 の誤識別
   - 推奨: AI 読取結果を目視確認してから確定

2. **黒塗り/訂正部分**
   - リスク: 消された数字が見える場合の誤読
   - 推奨: 目視確認必須

3. **複合テーブル**
   - リスク: セル境界の誤認
   - 推奨: 人間が確認・修正

4. **小さい文字**
   - リスク: メモ欄の小さい手書き文字
   - 推奨: 重要な場合は目視確認

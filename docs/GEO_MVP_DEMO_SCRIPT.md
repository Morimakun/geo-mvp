### 第1段：課題背景（1分）

「ジオソリューションズの営業支援で、現在以下の課題があると聞いています：

- FAX帳票とSalesforce CSVを手作業で突き合わせている
- 店舗名が正しく対応しているか確認に時間がかかる
- 手書き数字や正の字カウントは誤読のリスクがある
- 日付や実績値の整合性確認を人手で行っている

これらの確認作業を『自動化して欲しい』というご要望でした。」

### 第2段：実装アプローチ（1分）

「ただし、完全に自動確定するのではなく、『確認を支援するツール』として設計しています。

理由は：
- PDFの手書きは100%正確には読めない
- CSVにもデータの揺らぎや定義差がある
- 最終確認は必ず人間が行う設計にしたい

つまり、『事務局の確認負担を下げる』ことが目標です。」

### 第3段：本日のデモ内容（1分）

「本日は、実PDF 30ページと実Salesforce CSVを使って、
以下ができるようになったか、デモンストレーションします：

1. PDF帳票から店舗名と実績値を自動読取
2. 店舗名をSalesforceの店舗コードに自動変換
3. CSV側の対応する行を自動で特定
4. PDF値とCSV値を自動で比較
5. 一致・不一致・要確認を画面に表示
6. 事務局が確認するためのCSVを自動生成

では、実際にお見せします。」

## 🔒 安全設計の説明（2分）

### デモ中に強調する要点：

「このツールが『安全』である理由：

1. **複数候補は自動確定しない**
   - 候補が複数あれば『review』として人間判定
   - AIが勝手に1件に絞ったりしない

2. **読めない項目は『空欄』として扱う**
   - 『読めない = 0』ではなく『読めない = null（空欄）』
   - テンプレート値や不確実な手書きは値にしない

3. **最終確認は必ず人間**
   - 『この画面を見た事務局が最終判定する』設計
   - AIが勝手に確定する仕組みは一切ない

4. **危険な誤読は排除**
   - テンプレート値『40』を誤読する危険は完全排除
   - 『正の字が完成と判定される誤読』も0件

つまり『AI任せではなく、事務局が確認しやすくするツール』です。」

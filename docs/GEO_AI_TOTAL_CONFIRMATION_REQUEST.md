# AI（案件合計）欄 突合差分 ジオ様確認依頼

**作成日：** 2026-06-07
**対象：** Phase 6B v3 突合テスト（30ページ全件）
**目的：** PDF合計欄とSalesforce CSVの差分について、定義・マッピングを確定する

---

## 1. 概要

PDF（FAX日報）とSalesforce CSVの突合テストを実施したところ、**AI（案件合計）欄で13件の差分**が確認されました。

重要な点：

- ✅ **OCR自体はAI合計欄を100%読み取れています**（数字は正しく抽出できている）
- ⚠️ ただし、**PDFの合計欄とCSVの対応列・定義が完全に一致しているか未確認**です
- 📌 特に、**PDFのAI値とPDF内訳（AU+AV+AY+AZ）の合計が一致しないケースが12/13件**あり、AI欄の定義そのものの確認が必要です

この差分が「実際のデータ差分（ツールが正しく検出）」なのか「定義・マッピングのズレ」なのかを切り分けるため、ジオ様に確認をお願いしたく存じます。

---

## 2. 確認したい背景

### 対応表PDFに基づく AI/CZ の定義（確定）

受領済み対応表PDFおよびユーザー確認により、**AI と CZ の定義は以下のとおり確定**いたしました：

| 項目 | 定義 | 内訳列 | CSV列 |
|------|------|--------|-------|
| **AI（案件合計）** | **AU + AV + AY + AZ の4項目合計** | AU(47), AV(48), AY(51), AZ(52) | **35** |
| **CZ（別カテゴリ合計）** | **DL + DM + DP + DQ の4項目合計** | DL(116), DM(117), DP(120), DQ(121) | **104** |

→ **この定義を前提として、現在の突合ツール・ルールを固定しています**

### なぜ差分が出ているのか

このAI/CZ定義を前提としても、**13件の差分が出ている理由**は以下のいずれかと考えられます：

| 原因 | 該当状況 |
|------|---------|
| **A. PDF原紙の AI欄記入値確認** | P14=34、P11=20 など、大きな数字が本当にAI欄に書かれているか |
| **B. PDF内訳値(AU/AV/AY/AZ)の抽出不完全** | 内訳がnullで、AI値の妥当性を検証できない |
| **C. CSV列35 の集計タイミング・範囲** | Salesforce側の更新タイミング、集計範囲（当日分か累計か等） |
| **D. OCR読取位置** | AI欄として34/20を読んでいるが、原紙上の正しい位置か |

### 確認の趣旨

本依頼は「AI がどの列か」を尋ねるものではなく、**確定した AI/CZ 定義が正しいか、そしてこの定義での差分が実データ差なのか、集計タイミング差なのか、を切り分けるため**です。

## 5. ジオ様への確認事項（3点）

### 質問1：AI/CZの定義確認

こちらでは、対応表PDFおよび確認内容に基づき、**AI（案件合計）はAU+AV+AY+AZの4項目合計、CZ（別カテゴリ合計）はDL+DM+DP+DQの4項目合計**として扱っています。

- [ ] この理解で照合ルールを固定してもよろしいでしょうか？
- [ ] AIがAU/AV/AY/AZ以外の項目も含む場合は、ご教示ください。

> 📌 **背景：** 対応表PDFのご確認により、AIはAU/AV/AY/AZの4項目合計と理解いたしました。この定義を前提に13件の差分を分析しています。

---

### 質問2：PDF原紙のAI欄記入値確認

優先5ページについて、**PDF原紙のAI欄に本当に以下の数字が記入されているか**ご確認いただけますでしょうか。

- [ ] **P14（イオンモール神戸北）：「34」** が本当に書かれているか
- [ ] **P11（深江橋）：「20」** が本当に書かれているか
- [ ] **P24（六甲道）：「7」** が本当に書かれているか
- [ ] **P12（広畑）：「0」または「空欄」** か
- [ ] **P28（宝殿）：「0」または「空欄」** か

> 📌 **背景：** P14/P11では差分が-31/-18と大きく、原紙確認でAI読取の信頼性を判定したいためです。

---

### 質問3：Salesforce CSV列35（AI）の集計定義確認

Salesforce CSV列35（AI）について、以下をご確認ください。

- [ ] CSV列35（AI）は、**PDFのAI欄と同じくAU/AV/AY/AZの当日合計**として出力されていますか？
- [ ] **更新タイミング**（当日中、翌日など）に遅延はありますか？
- [ ] **集計範囲**（営業日のみか、カレンダー日か、累計か）は何ですか？
- [ ] PDFと同じく「当日分の合計」で一致していますか？

> 📌 **背景：** P12/P28ではPDF=0/空欄なのにCSV=2という逆パターンが出ており、Salesforce側の集計期間・更新タイミングがPDFと異なる可能性を確認したいためです。

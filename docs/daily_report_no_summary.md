## 🔍 詳細分析

### 1. 読取率と欠落

- **成功率**: 28/30 ページ = 93%
- **欠落ページ**: 2ページ（ページ9、ページ21）
  - ページ9: `staff_name` が読み取れず（森田 真司は登録済み）、`daily_report_no` は空欄
  - ページ21: `staff_name` が読み取れず（池崎 荒治は登録済み）、`daily_report_no` は空欄

**判断**: データの欠落ではなく、**該当行の読取不可**と思われる

---

### 2. 重複パターン

```
重複あり: 1件

00157858 (ページ2, ページ10)
  - ページ2: 2026-05-17, 担当者「909」
  - ページ10: 2026-05-18, 担当者「（いない）」← 別の帳票

異なる日付、異なる担当者なのに同じNo
→ 「帳票番号」というより「共通参照No」 or 「システム生成ID」の可能性
```

**判断**: 
- 大多数（68%）が「00157」で始まる

- 担当者固有番号なら、「00157」を共有しない理由が不明

---

### 4. 担当者別の日報データNo 分析

#### 複数の日報DataNo を持つ担当者

```
2人のみ複数の異なるNo を持つ:

1. 森田 真司: 2つの異なるNo
   - 00157866 (ページ14)
   - 00157936 (ページ17)

2. 羽曳野伊賀: 2つの異なるNo
   - 001579 06 (ページ23)
   - 00157966 (ページ27)
```

#### 単一の日報DataNo を持つ担当者

- 23人の担当者は**各1つの日報DataNo のみ**に見えるが...
- ただし**人間の目視確認で、同じ店舗でも提出日によって日報データNoが変わっているケースが発見された**

**判断**: 
- 「担当者固有番号」ではない可能性が高い
- むしろ、帳票ごと・提出日ごとに変わる番号である可能性が高い
- 見かけ上「担当者ごとに同じNo」に見えるのは、分析期間内で各担当者が1回のみ提出したためと考えられる

## 🤔 現在の仮説（修正版）

### ⭐ 有力仮説: 「帳票ごと・提出日ごとの管理番号」

| 根拠 | 強度 |
|-----|------|
| **人間目視で、同じ店舗でも日によって日報DataNoが変わっているケースを確認** | ★★★ |
| 重複が存在する（同じNo が異なる日付の帳票に） | ★★★ |
| 担当者固有番号ではない可能性が高い | ★★★ |
| 混合形式や特殊文字が含まれる | ★★ |

**説明**: 見かけ上「担当者ごとに同じNo」に見えるのは、分析期間内で各担当者が1回のみ提出したのためと考えられる。

### 仮説B（対比）: 「担当者ごとの番号」（可能性は低い）

| 根拠 | 強度 |
|-----|------|
| 23人の担当者が分析期間内で各1つのNo のみ | ★★ |
| 先頭「00157」が共通（19件） | ★ |

**問題点**: 
- 同じ店舗でも日によってNo が変わる事例がある
- これは担当者固有番号と矛盾する

## ⚠️ 確認が必要な項目

### 片山様への主要確認事項

**最重要確認**:

**日報データNoは、担当者ごとの固定番号ではなく、帳票ごと・提出日ごとに変わる番号でしょうか？**

人間の目視確認では、同じ店舗でも日によって日報データNoが異なっているケースが見つかりました。
これは、「担当者固有番号」ではなく、「帳票または提出データ単位の番号」である可能性を示唆しています。

### その他の確認事項

1. **形式が混在する理由は何か**
   - 8桁（00157846）
   - 6〜7桁（157816, 0015785）
   - 特殊文字（157P05, 7272×h, 0015N939）

2. **同じNo が複数ページに出現することはあるか**
   - データ例：00157858 が ページ2 と ページ10 に出現
   - これは帳票番号の重複？それとも異なる意味？

3. **欠落ページ（ページ9, 21）は何が原因か**
   - 帳票の様式が異なるか
   - 担当者不在時のデータか
   - 読取エラーか

4. **Salesforce CSVには出力されない理由は何か**
   - CSV出力時に除外しているか
   - そもそも CSVに保存されていないか
   - 別の列名で保存されているか

## 📌 結論

### 暫定判断（人間目視確認後）

**日報データNo は、担当者固有番号ではなく、帳票ごと・提出日ごとに変わる番号である可能性が高い。**

- 同じ店舗でも提出日によってNo が異なるケースを確認

- 担当者固有番号という仮説は否定される可能性が高い

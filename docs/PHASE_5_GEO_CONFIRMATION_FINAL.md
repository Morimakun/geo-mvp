## 確認事項（5項目）

### ✅ 1. 再送FAXの扱い

**確認内容:**

同一店舗・同一営業日で複数版のFAXが届く場合（初版→修正版）、**後送分を正として扱う認識でよろしいか**。

**背景:**
- 実績例：P2（初版 AI=1, 19:44送信）vs P10（修正版 AI=2, 20:12送信）
- Salesforce CSV値：2（後送版ベース）

**回答例:**
```
✅ 後送優先で運用する
❌ 初版を保持する
❓ ケースバイケース（別途ルール化）
```

---

### ✅ 2. 照合基準日は「帳票内営業日」

**確認内容:**

照合対象日の判定は、**FAX送信日ではなく、帳票内に記載された営業日（対象日）を基準にする認識でよいか**。

**背景:**
- P26/P27/P28は FAX送信日=5/19 ですが、帳票内営業日は別の可能性がある
- 台風・締め遅れ・翌日送信のケースに対応するため、FAX送信日だけでは「対象外」と判定できない
- **見るべきは帳票内の「営業日」「対象日」フィールド**

**確認項目:**
1. FAX帳票のどのフィールドに「営業日」が記載されているか
2. FAX送信日 ≠ 営業日 のケースは実務的に発生するか
3. 期間選択時は、カレンダーで営業日を選ぶのか、FAX受信日を選ぶのか

**回答例:**
```
✅ 帳票内営業日を基準にする（FAX送信日は参考値）
❌ FAX送信日を基準にする
❓ 両方合わせて判定する（詳しい規則を確認）
```

---

### ✅ 3. カレンダー営業日での照合運用

**確認内容:**

本システムでは、**ユーザーがカレンダーで営業日を選択 → その日分の帳票と、その日分のSalesforce CSVを照合する**という運用で、よろしいか。

**背景:**
- 帳票の営業日を正確に判定することで、FAX送信タイミングのズレに対応可能
- 例：5/17営業分のFAXが5/18に届いても、5/17分のCSV行と照合できる

**回答例:**
```
✅ その通り。営業日ベースで運用する
❌ FAX受信日ベースで運用する
❓ 営業日 or FAX受信日の選択式にしてほしい
```

---

### ✅ 4. 同一店舗・同一営業日で複数帳票がある場合のCSV仕様

**確認内容:**

同一店舗・同一営業日で「店頭」「イベント」など複数形式の帳票がある場合、Salesforce CSVでは：

1. **別行で入力されるのか**
2. **1行に合算されるのか**
3. **「営業形式」などの区分列があるのか**

**背景:**
- 実績例：イオンモール神戸北 5/17で、「店頭」「イベント」2つの帳票（P14/P9）
- CSV側で「複数営業形式」をどう区別するかが不明

**回答例:**
```
✅ 別行で入力される（営業形式ごとに区別）
❌ 1行に合算される
❓ 営業形式により異なる
```

---

### ✅ 5. 店舗マスター（店舗名⇔取扱コード）の正式化と更新ルール

**確認内容:**

いただいた「**店舗名　スタッフ名.xlsx**」（24店舗）を**正式な店舗・スタッフマスター**として使ってよいか。

また、今後の**店舗追加・統廃合・スタッフ異動があった場合、どのように更新するか**。

**背景:**
- 現在は受領済みの Excelで24店舗の対応を確認済み
- 本運用では「正式版」として位置づけ、更新ルールを確立する必要あり

**確認項目:**
1. このExcelが正式マスターでよいか
2. 更新時は「新しいExcel差し替え」でよいか、それとも「API連携」が必要か
3. 更新タイミング（月次 / 四半期 / 随時）

**回答例:**
```
✅ 正式マスターとして使用。新しいExcel差し替え運用
✅ 正式マスターとして使用。Salesforce連携で自動更新
❓ 別途マスター管理の仕組みが必要
```

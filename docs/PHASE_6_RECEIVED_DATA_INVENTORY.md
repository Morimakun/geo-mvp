## 4. 重要な発見

1. **「CSVファイル」ではなく多シートExcel**：Salesforce CSV相当データは各ブック内の`CSV`シート。旧検証時の生CSVとは列番号が異なる（詳細は SCHEMA_CHECK 参照）。
2. **店舗別転記シートの存在**：ジオ側で新帳票の記入内容をExcelに転記している。帳票の通し番号1〜104と同じ構造で、AI/CZ合計欄相当の値・検算欄まで入っている。**照合の正解値（グラウンドトゥルース）として利用できる可能性が高い。**
3. **PDFには新旧帳票が混在**（新帳票46枚・旧帳票17枚・判読不能/無関係写真3枚。詳細は PAGE_QUALITY_REVIEW 参照）。

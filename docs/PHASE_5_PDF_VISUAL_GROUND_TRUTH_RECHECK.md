## 📞 技術的な理解（参考）

### CSV 値と PDF 目視値が異なる理由

今回の検証で、**CSV値とPDF原票の目視値が異なるケースが複数確認されました**。これは以下の理由が考えられます：

1. **CSV入力時の誤り**: Salesforce に入力する際に手入力誤りがあった可能性
2. **日付境界**: FAX作成日とCSV入力日がズレている可能性
3. **複数版の存在**: FAX修正版とCSV入力版のズレ
4. **セル参照間違い**: CSV側で異なるセルを参照している可能性

### 重要な結論

> **PDF原票の目視確認により、CSV値をそのまま「正解」とは言えないケースが存在することが判明しました。**
>
> 今後の照合判定では、PDF目視値を最終的な正解として扱う必要があります。
